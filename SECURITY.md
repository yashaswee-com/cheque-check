# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through the
[Cheque Check contact page](https://chequecheck.in/contact). Do not report
unresolved vulnerabilities in a public issue or discussion.

Include the affected component or URL, the observed impact, and concise
reproduction steps using non-sensitive test data. Do not include passwords,
tokens, customer records, or other private information.

This repository does not publish a response-time guarantee or a bug bounty
program. The [security and known risks guide](docs/security-and-known-risks.md)
describes repository-level controls and deployment boundaries; it is not a
substitute for reporting a new finding.
