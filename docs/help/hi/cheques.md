# चेक मैनेज करें

चेक Cheque Check का मुख्य रिकॉर्ड है। यह पेमेंट को पार्टी, बैंक खाते, तारीख, राशि और स्थिति से जोड़ता है।

## चेक कैसे बनाएं

1. Cheques सेक्शन में जाएँ
2. Add new cheque चुनें
3. पार्टी चुनें
4. बैंक खाता चुनें
5. चेक नंबर, राशि और तारीख भरें
6. स्थिति और प्रकार चुनें
7. सेव करें

## चेक कैसे अपडेट करें

1. चेक सूची खोलें
2. सही चेक चुनें
3. विवरण बदलें
4. सेव करें

## चेक की स्थिति कैसे देखें

सामान्य रूप से चेक की स्थिति हो सकती है:

- Pending
- Issued
- Paid
- Cleared
- Returned
- Cancelled

## चेक ढूँढें और फ़िल्टर करें

1. Cheques सेक्शन खोलें
2. search या filter का उपयोग करें
3. पार्टी, बैंक, राशि, तारीख, या स्थिति चुनें
4. परिणाम देखें

## अच्छी आदतें

- चेक दर्ज करने में जल्दी करें
- पार्टी और खाते की जांच करें
- स्थिति समय पर अपडेट रखें
- लंबित चेक नियमित रूप से देखें

## संक्षेप

चेक ही पूरे ऐप का केंद्र है। यह बताता है कि पैसा कहाँ जा रहा है, किसके लिए है, और क्या अभी करना है।
