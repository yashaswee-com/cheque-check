# रिमाइंडर और नोटिफिकेशन सेट करें

रिमाइंडर आपके काम की याद दिलाते हैं। इससे आप महत्वपूर्ण चेक, फॉलो-अप, या भुगतान के काम को भूलने से बच सकते हैं।

## रिमाइंडर कैसे सेट करें

1. उस चेक या काम को खोलें जिसे याद रखना है
2. Reminder या Notification विकल्प चुनें
3. तारीख और समय तय करें
4. सेव करें

## रिमाइंडर का महत्व

- देय तिथियों की याद दिलाना
- फॉलो-अप याद रखना
- भुगतान को समय पर पूरा करना
- टीम या ग्राहक के साथ सही समय पर संपर्क करना

## अच्छी आदतें

- समय से पहले रिमाइंडर लगाएँ
- जरूरी काम को हाइलाइट रखें
- नियमित रूप से रिमाइंडर देखें
- स्थिति बदलते ही अपडेट करें

## संक्षेप

रिमाइंडर आपके काम का सहायक हैं। वे आपको समय पर याद दिलाकर गलतियाँ कम करते हैं।
