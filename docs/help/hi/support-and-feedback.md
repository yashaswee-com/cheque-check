# Feedback, roadmap और support

Problem report, product suggestion या account help के लिए app के support tools उपयोग करें।

## Help search करें

**Settings → Help & Support** में in-app FAQ question/category से खोजें। Related questions setup, cheque entry, scanning, plans, notifications और security पर मदद देते हैं।

## Feedback भेजें

1. **Feedback** खोलें।
2. **Report a bug**, **Request a feature** या **Other feedback** चुनें।
3. Clear title और description लिखें: क्या किया, क्या हुआ, क्या expected था।
4. मददगार हो तो अधिकतम दो supported files जोड़ें, कुल 10 MB तक।
5. Submit करें और **Your submissions** में status देखें।

Supported attachments JPEG, PNG, WebP, PDF या plain text हैं। एक घंटे में अधिकतम पाँच feedback submissions हो सकते हैं।

Bug report और ordinary feedback private रहते हैं। Feature request team द्वारा publish होने पर roadmap में आता है।

## क्या शामिल करें

Problem के लिए:

- इस्तेमाल किया route या feature;
- reproduce करने के steps;
- expected और actual behavior;
- समय, browser और device;
- private information हटाने के बाद safe screenshot/document।

Passwords, verification codes, card details, online-banking credentials, complete account numbers या unnecessary personal data न भेजें।

## Roadmap देखें

Signed-in roadmap published feature requests और status दिखाता है। Feedback area से अपनी submissions search/filter कर सकते हैं।

Feature request submit होने से approval, schedule या build की guarantee नहीं है।

## Support से संपर्क

Help & Support page पर:

- `support@chequecheck.com`;
- WhatsApp support;
- in-app FAQ और feedback tools।

Payment/access समस्या में order या transaction ID दें, पर card details न दें। Cheque/account समस्या के लिए workflow बताएँ और full export के बजाय minimally redacted screenshot दें।

## Announcements और What's New

**Settings → What's New** और **Announcements** app में उपलब्ध product updates/messages दिखाते हैं। Checked-in feature या announcement हर account के hosted deployment की proof नहीं है।
