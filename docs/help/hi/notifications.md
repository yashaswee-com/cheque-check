# रिमाइंडर और नोटिफिकेशन

Notifications में in-app inbox, scheduled reminder work और optional browser/communication channels आते हैं। **Notifications** खोलने से cheque status नहीं बदलता और अपने-आप सारे items read नहीं होते।

## Reminder timing चुनें

**Settings → Notifications** में देखें:

- configured date से 1, 3 या 7 दिन पहले का warning period;
- रोज़ reminders की संख्या;
- selected time zone में reminder times;
- हर channel की On/Off state और consequence।

Changes आगे schedule होने वाले reminder work पर लगते हैं। हर provider हर message deliver करेगा, यह साबित नहीं होता।

## Inbox

Inbox में cheque reminders और report-export updates आते हैं। आप:

- active business या सभी businesses देख सकते हैं;
- event type या business name से search;
- newest/oldest sort;
- unread filter;
- visible business scope के items read;
- refresh और load failure पर retry कर सकते हैं।

Lock-screen/device notification में cheque details नहीं आतीं।

## Voice reminders

Voice reminders eligible issued cheques के बारे में daily scheduled calls हैं। इनके लिए:

- Features page पर valid phone number saved;
- Voice Reminders चालू;
- active access period और available call credits;
- configured delivery provider।

**Send test call** एक available call credit उपयोग करता है। Queued call completed call की guarantee नहीं है।

## इस device पर push

Push permission केवल enable चुनने पर माँगी जाती है।

1. **Settings → Notifications** खोलें।
2. Device push status देखें।
3. **Enable on this device** चुनें।
4. Browser permission दें।

Browser, HTTPS या installed iOS app requirement पूरी न हो तो push उपलब्ध नहीं रहेगा। एक account पर अधिकतम 10 registered devices हैं।

## अन्य channels

- **Party SMS** Premium option है जो cheque create/status change पर phone के SMS app में message तैयार करने का प्रस्ताव देता है। Carrier charge लग सकता है।
- **SMS reminders** और **WhatsApp reminders** preferences हैं; delivery deployment configuration पर निर्भर है।
- Voice, AI scan और Premium के access/credits अलग हैं।

## समस्या आने पर

- Channel on है या नहीं और consequence line पढ़ें।
- Reminder days, daily frequency, time zone और times जाँचें।
- Voice credits और phone number जाँचें।
- Push browser permission जाँचें।
- Online होकर inbox refresh करें।
- केवल notification पर निर्भर न रहें; महत्वपूर्ण cheque record सीधे देखें।
