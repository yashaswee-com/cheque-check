# बैंक खाते मैनेज करें

Cheque Check में बैंक खाता वह स्थान होता है जहाँ चेक दिया जाता है, प्राप्त किया जाता है या ट्रैक किया जाता है।

## बैंक खाता कैसे जोड़ें

1. Accounts सेक्शन में जाएँ
2. Add account चुनें
3. खाता नाम और बैंक जानकारी भरें
4. सेव करें

## बैंक खाता कैसे अपडेट करें

1. Accounts सूची खोलें
2. खाता चुनें
3. जानकारी बदलें
4. सेव करें

## डिफ़ॉल्ट खाते का चयन करें

1. Account settings में जाएँ
2. Default mark करें
3. सेव करें

## खाते को बंद या हटाएं

1. खाता विवरण खोलें
2. delete या deactivate चुनें
3. पुष्टि करें

## अच्छे नियम

- खाता नाम साफ रखें
- duplicate खाता न बनाएं
- पुराने खाते को inactive रखें
- default खाता सही रखें

## संक्षेप

बैंक खाते बताते हैं कि पैसा कहाँ है। इससे सारे चेक रिकॉर्ड सही और समझ में आने वाले बनते हैं।
