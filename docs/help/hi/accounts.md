# बैंक खाते मैनेज करें

एक account किसी एक बिज़नेस से जुड़ा होता है और दिखाता है कि चेक किस बैंक खाते से है। Cheque Check खाते की जानकारी रिकॉर्ड करता है; यह बैंक से कनेक्ट होकर balance नहीं पढ़ता।

## खाता जोड़ें

1. **Accounts → Add Account** खोलें।
2. Account holder का नाम भरें।
3. Indian bank directory से बैंक चुनें या ज़रूरत हो तो private custom bank बनाएँ।
4. Account number और 11-character IFSC भरें।
5. Optional opening balance, notes, color, image और tags जोड़ें।
6. चाहें तो इसे default account बनाएँ।
7. सेव करें।

IFSC check केवल format जाँचता है। यह account, branch या balance की वास्तविक जाँच नहीं है।

## चेक भरते समय खाता बनाना

चेक फ़ॉर्म में खाता न हो तो **Add new account** चुनें। सेव करने के बाद चेक पर लौटें और नया खाता चुनें। AI scan account details सुझा सकता है, लेकिन सेव करने से पहले जाँच ज़रूरी है।

## Default account

हर बिज़नेस में एक default account हो सकता है। नया चेक अपने-आप इसे चुनता है, पर सेव करने से पहले बदला जा सकता है।

1. Account edit करें।
2. **Use as default account for new cheques** चालू करें।
3. सेव करें।

नया default सेव करने पर उसी बिज़नेस का पुराना default बदल जाता है।

## खाता edit या organize करें

Account खोलकर details, image, notes, tags या default setting बदलें। Account list में search और bank filter उपलब्ध हैं।

## खाता हटाएँ

खाता तभी delete करें जब उसकी ज़रूरत न हो। किसी published या draft cheque द्वारा use होने पर deletion रुकता है।

Cheque history ज़रूरी हो तो खाता रखें और details update करें। Deleted data के लिए self-service restore screen उपलब्ध नहीं है।

## अच्छी आदतें

- साफ़ और अलग नाम रखें।
- पूरा account number और IFSC जाँचें।
- Default को सबसे ज़्यादा इस्तेमाल होने वाले खाते से जोड़ें।
- Tags को grouping के लिए रखें, bank details की जगह नहीं।
- Notes में online-banking password या card PIN न लिखें।
